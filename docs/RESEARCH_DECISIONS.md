# GRAFT-GS research decision record

This record is normative for the implementation.  Complexity uses `M` image
particles, `V` active charts, `E_OT` transport edges, `E` chart edges, and `F`
faces.  All topology guarantees are conditional on the assumptions recorded in
`MATHEMATICAL_ASSUMPTIONS.md`.

## Architecture decision matrix

| Subsystem | Problem and candidates | Selected formulation | Preserved invariants and rationale | Complexity / memory | Principal failure modes |
|---|---|---|---|---|---|
| Dataset contract | Filename inference, schema-specific loader, manifest-first typed measures, independent modality datasets | Physical-file-verified object manifest with explicit direct/derived/pseudo-label provenance and synchronized variable-view loading | A camera manifest never implies an image exists; continuous alpha is separated from evidence validity; sparse surface voxels are not promoted to volume truth; every camera/image tensor shares one frame index | Manifest audit `O(number of files + array headers + surface vertices)`; per sample `O(KHW+N)` | Remote-corpus producer-version drift, incomplete view sets, semantically corrupt but syntactically present artifacts |
| Upstream deployment boundary | Fixed workstation paths, repository siblings, installed packages, explicit server checkouts, model-hub cache | Explicit environment checkout, then physically present declared server checkout, then installed-package fallback, all with origin validation; checkpoint precedence is CLI, GRAFT environment, compatible legacy environment, official released ID | The adapter executes the audited upstream project module/checkpoint rather than a same-named accidental import. No workstation path or object identity controls deployment. | Import/checkpoint resolution is constant-time metadata work; isolated real-view preflights load one model at a time | Stale project API, cache miss, configured-root/module-origin mismatch, upstream checkpoint schema drift |
| Corpus discovery | External ID catalog, render-directory enumeration, union of every filename, repeated per-object probing, indexed modality intersection | One-pass per-modality artifact index; candidate union from latent/normalized-mesh primary trees; configurable required intersection plus explicit optional availability | Dataset membership follows physically coexisting producer artifacts rather than an example ID. Optional pseudo-label/surface modalities never fabricate zeros or discard otherwise valid observations. Relative structural maps preserve root relocatability. | `O(F log F)` deterministic indexing for `F` serialized artifacts and `O(NM)` intersection bookkeeping for `N` candidates, `M=9` modalities; avoids the former `O(NF)` repeated walks | Multiple model variants for one modality are intentionally ambiguous unless the corpus is normalized or an explicit selection policy is introduced; a producer may leave syntactically present but semantically corrupt files, which are rejected during audit |
| Cross-model pseudo features | Direct DINO/TRELLIS channel regression, learned MLP adapter, feature concatenation, relational kernel alignment | Confidence-weighted edgewise cosine-kernel alignment after exact surface-cell-to-chart assignment | Learned channel bases of VGGT, DINOv2, and TRELLIS are not identified, so direct coordinate regression is rejected. Pairwise similarity is dimension-independent and gauge invariant when computed from `0e` chart fields; pseudo labels never become geometry or topology truth | Assignment/aggregation `O(N)` and overlap-edge comparison `O(E)`; no dense token attention or cross-feature matrix | Teacher representation bias; charts without two supervised adjacent cells receive no relation; cosine geometry discards feature norm information |
| Evidence lift | Partial OT, KL-unbalanced OT, fused GW, Schrödinger bridge, probabilistic correspondence | Sparse fused geometric KL-UOT with ray-aligned covariance, physical area mass, visibility support, and implicit differentiation | Mass remains a geometric measure; KL relaxation rejects background and permits unseen atlas mass. FGW is reserved as a multiscale regularizer because pairwise intra-measure terms would raise a local solve from `O(E_OT)` to at least quadratic neighborhood coupling. A Schrödinger bridge is unjustified for a static one-step correspondence unless a calibrated stochastic observation process is learned. | `O(E_OT)` state and Sinkhorn work per iteration; chunked support construction avoids `V*M` storage | Poor uncertainty calibration; disconnected support; entropic bias; nearly balanced relaxation slows the implicit solve |
| Supervised gauge and uncertainty | Direct camera replacement, per-view alignment, scene Sim(3), mesh-rasterized depth, quantized surface likelihood | Joint differentiable scene Sim(3) for VGGT geometry plus Gaussian evidence NLL against surface cells with `h^2/12 I` quantization variance | Predicted depth/rays/cameras stay projectively consistent; only global gauge is removed; relative camera error remains; learned SPD covariance cannot collapse onto voxel centers | Camera solve `O(K)` plus one batched 3x3 SVD; exact chunked surface assignment `O(MN)` time and `O(chunk*N)` memory in the reference path | Degenerate camera centers; SVD ambiguity under symmetric rigs; voxel surface misses sub-cell geometry; nearest-sample switches are nonsmooth |
| Transport objective | Entropic OT, debiased Sinkhorn divergence, partial mass cap | KL-UOT plan and its exact sparse primal objective | The positive plan is required for barycentric chart statistics. Debiasing was rejected for the reference path because source-source and target-target support truncations introduce a second, support-dependent approximation while tripling solve cost; it remains an ablation. Partial OT requires a prescribed transported mass that is not identifiable under unknown visibility. | One sparse solve; `O(E_OT)` objective evaluation | Entropic blur when epsilon is too large; assignment brittleness when too small; regularized objective is biased |
| Implicit UOT convergence | Fixed iteration count, iterate-delta logging, unrolled differentiation, silent approximate adjoint, exact sparse implicit solve | Coupled fixed-point equation residual with a relative scale; fail-closed forward/adjoint convergence; FP64 log-domain potentials and conditional Jacobian probabilities; explicit FP32 storage-underflow telemetry | No unconverged plan or gradient can seed the atlas; implicit differentiation retains linear iteration memory rather than an unrolled tape. Soft unbalanced marginals may become exponentially small without fabricating a per-edge mass floor. | `O(E_OT)` per fixed-point/adjoint iteration; FP64 plan/potential workspaces; residual host synchronization every eight iterations instead of every iteration | Nearly balanced relaxation may exceed the iteration budget; an all-underflow storage plan is rejected; a high fraction of zero stored marginals signals cost/support miscalibration and fails the view-budget accuracy gate |
| UOT storage-error admission | Zero-edge/zero-row count threshold, force a positive FP32 floor, retain all plans in FP64, FP64-referenced mass/error certificate | Keep FP64 log-domain solve and implicit Jacobian; return FP32 geometric state; measure underflowed mass, zero-row/column mass, and total relative L1 cast error against the FP64 plan | Sparse UOT can contain many intentionally negligible edges. Count fraction is unrelated to measure error and falsely rejected the supplied 16/24/32-view reports. A positive floor would fabricate transport; universal FP64 storage doubles the dominant sparse state. | Four linear reductions over `E_OT`; no additional retained tensor beyond masks/reductions | The certificate bounds plan storage error, not downstream nonlinear sensitivity; a configured relative-L1 tolerance remains empirical and fail-closed |
| Frozen-upstream CUDA allocator lifetime | Ignore cache, gate historical peak reservation, unload TRELLIS weights, sample on every rank, release inactive source-rank blocks | With audited root bounds, sample/synchronize TRELLIS before VGGT; sample only on the designated rank; after sparse coordinates and exact CPU cache are materialized, synchronize and call `empty_cache`; assert live allocated bytes are invariant; gate live peak plus ending allocator/driver headroom | PyTorch cached reservation is not active geometry. The supplied near-constant 98.5% rank-0 reservation is consistent with dead TRELLIS diffusion workspaces, while other ranks do not sample. Early frozen-prior execution avoids overlap with VGGT's differentiable tape; releasing inactive blocks preserves weights, values, precision, and gradients and prevents native CUDA rasterizers from being starved by allocator ownership. | One device synchronization/cache release on the first exact conditioning-cache miss per object/seed; subsequent hits do not repeat diffusion sampling | `empty_cache` can add latency on cache misses; inference without explicit bounds cannot prefetch; external allocations are only observed through driver-free memory, not PyTorch active bytes; full A800 measurements remain required |
| Spatial representation | Fixed sparse voxels, adaptive octree, simplicial complex, neural implicit field, wavelets | Persistent 2:1-balanced octree carrying explicit quadratic charts and a selected simplicial surface complex | Stable Morton identity supports multilevel supervision and checkpoints; charts preserve continuous differential geometry; the simplicial complex carries topology independently of octree occupancy. No isovalue is required. | `O(V+E+F)` state; refinement `O(M log V)` assignment plus local fits | PCA frame ambiguity at isotropic neighborhoods; quadratic charts fail beyond their injectivity radius; incorrect topology proposal cannot be repaired by continuous flow |
| Hidden-surface support | Late prior scores on observed nodes, pseudo-particles in image OT, independent TRELLIS decoding, empirical structured support measure | A Jeffreys-smoothed Beta-Bernoulli measure from multiple TRELLIS structure samples seeds additional canonical atlas cells; observed/prior mass, count, and posterior variance remain separate, image particles remain the only UOT target, and topology occupancy uses a lower-confidence additive surface hazard. Exact conditioning/seed hashes bound a deterministic LRU, same-object DDP samples only on source rank, and a temporary decoder hook obtains the authoritative output grid independently of the lower-resolution flow latent. | The prior can propose genuinely unseen support without becoming an observation, ground-truth label, feature concatenation, or asset decoder. Repeated samples dominate one-off hallucinations; low-retention UOT rows shrink to their atlas charts instead of acquiring arbitrary nearest-image barycenters. Exact-byte cache identity preserves the uncached integer support. Decoder-shape capture is preferred to hard-coding 64 or using a biased occupied-coordinate maximum. | Cache miss: TRELLIS flow plus coordinate union/voting `O(SP log(SP))`; cache hit: `O(KHW)` exact hash plus support transfer; decoder-hook work is constant-time shape metadata and atlas/UOT complexity grows only with admitted support | TRELLIS coordinate-frame or upstream decoder-contract mismatch; correlated posterior samples invalidate independent-cell variance aggregation; hallucinated support; cache host-transfer overhead when views rarely repeat; an over-strong hazard prior can dominate weak observed geometry |
| Refinement | Isotropic variance split, curvature split, image-plane disagreement, anisotropic metric adaptation, PH-guided refinement | Geometry residual, curvature, occupancy entropy, and sparse plan-conditional image reprojection variance with 2:1 closure; discrete assignment followed by conditionally differentiable chart fitting | Isotropic cells preserve Morton nesting; evidence precision determines the continuous anisotropic metric. Retained scene camera tables make the cross-view statistic exact in the calibrated image model, normalized by projected cell scale. Functional post-split fitting preserves continuous gradients without inventing a gradient for Boolean split indices. | `O(E_OT log E_OT)` grouping plus linear projection/moments and local chart fits; camera storage `O(K)`, not `O(E_OT)` | Calibration/occlusion error can trigger excessive splits; a single-view chart has no cross-view statistic; under-refinement of unobserved thin structures |
| Continuous atlas metric | Nearest chart metric, linear blend, log-Euclidean blend, affine Karcher mean, compact partition of unity | Compact smooth bump partition of unity with a nearest-chart fallback outside support; positive weighted sum of chart SPD metrics | Convex SPD closure gives a simple exact positivity guarantee and SE(3) covariance. Log/Karcher means add iterative matrix functions without improving the node-based flow contract enough to justify their cost. | Reference query `O(QV)` in chunks; no dense state is retained | Nearest fallback is nonsmooth at exterior Voronoi boundaries; badly scaled chart metrics remain badly conditioned |
| Equivariant processing | SE(3) transformer, TFN, e3nn attention, Lie convolution, local-frame gauge network | Connection-aware sparse transport attention over `0e`, `1o`, `2e`, with exact local-frame parallel transport and parity-valid tensor products | Global SE(3) invariance follows from local coordinates; local gauge covariance follows from `P_ji=R_i^T R_j`; multiplicity maps never mix magnetic components. Exact Cartesian symmetric-traceless tensors avoid numerically evaluating Wigner-D matrices for `l=2`. | `O(E*C)` messages, `O(V*C^2)` multiplicity projections; no dense attention | Frame discontinuities if the connection is not synchronized; neighborhoods with no edges; high-order information limited to `l<=2` |
| Equivariant residual stability | Unbounded residual maps, local spectral normalization, exact global Lipschitz analysis, small-step normalized messages | Spectrally parametrized multiplicity maps with an effective configured operator scale, bounded normalized messages, sigmoid gates, and explicit residual scales; global certification still requires a measured composed field bound | Scaling acts only on irrep multiplicities and therefore preserves gauge/SE(3) laws. A real configuration control is preferable to dead `spectral_bound` metadata, while avoiding an unsupported claim that local bounds multiply tightly through dynamic sparse attention. | Spectral power iteration per parametrized map; no added state tensor or representation mixing | One-iteration spectral estimates can be loose during training; tensor/radial paths and heads determine the composed field bound; empirical server calibration remains necessary |
| Topology proposal | Occupancy threshold, PH penalty only, discrete Morse, alpha/witness complexes, learned autoregressive complexes | Structured distribution whose cuts include the maximal-support filtration endpoint, exact lower-star persistence birth/death events ranked by lifetime, and quantile/fixed coverage; an evidence-filtered clique surface complex uses parity-union-find insertion, exact Z2 persistence, hard incidence/orientability checks, and energy selection | Topology is selected before flow. The terminal support cannot disappear merely because every positive heuristic cut removes overlap triangles. Betti numbers and boundary operators are exact per candidate; a conflicting face is rejected without erasing an admissible orientable component. The endpoint still competes under all evidence/prior/complexity energies. | One reference persistence reduction plus candidate construction approximately `O(V*d^2)` for degree `d`; near-linear inverse-Ackermann orientation constraints; bitset persistence near `O(N_cells^2 / word_size)` worst case | Clique triangulation can miss nonlocal faces or fill a true handle; maximal support may include weak prior cells; a finite critical-cut family does not enumerate alternate discrete-Morse matchings/connectivities |
| Persistence-diagram comparison | Dense exact Hungarian, entropic diagram OT, persistence images/landscapes, random sliced Wasserstein, deterministic sliced Wasserstein | Remove exact zero-lifetime diagonal pairs; retain exact diagonal-augmented Hungarian matching for at most 512 total points; above that budget use 32 deterministic midpoint directions with exact sorted 1D diagonal-augmented couplings | The GF(2) persistence diagrams remain exact. Small reference tests retain the original metric. The large path preserves symmetry, identity and piecewise filtration gradients without allocating a pairwise matrix; unlike persistence images it does not rasterize or choose a bandwidth. | Exact `O(P^2)` memory/`O(P^3)` time for `P<=512`; sliced `O(P)` peak working memory and `O(L P log P)` time | Finite-direction sliced distance is an approximation to the full diagram Wasserstein geometry; sorting ties select a subgradient; Phase-specific calibration of the learned persistence weight remains empirical |
| Mesh-derived geometric supervision | Full-view batched CUDA rasterization after model forward, CPU rasterization, offline target materialization, deterministic CUDA view chunks before forward | Exact audited cameras and one shared triangle soup are rasterized in contiguous two-view nvdiffrast chunks before any trainable graph is constructed; per-view tensors are concatenated in manifest order | Rasterization is separable over views, so chunking changes neither camera geometry nor triangle visibility. Raw nonmanifold connectivity remains only triangle-soup geometry. Scheduling immutable targets first prevents renderer workspace from overlapping model activations without detaching a learned path. | Mesh state `O(V_m+F_m)`; target storage `O(KHW)`; transient transformed geometry/raster workspace `O(C(V_m+HW))` for chunk size `C=2`, rather than `O(K(V_m+HW))` | Upstream nvdiffrast may change numerical reduction behavior; equivalence is conditional on independent shared-topology instance rendering and is tested on the audited A800 sample |
| Topology supervision provenance | Raw mesh as truth, manifold repair, differentiable persistence target, teacher pseudo-label, unavailable label | Typed raw/validated/repaired/derived/teacher states with hard masks, nullable targets, and confidence-weighted expected Betti mismatch | Invalid connectivity cannot become `(0,0,0)` or silently activate a loss. Mesh geometry remains usable for rasterization. Persistence requires a declared filtration and stratum labels require atlas correspondence. | Raw audit `O(F log F)` from edge grouping; supervised candidate mismatch `O(C)` for `C` strata | Repair changes topology; teacher bias; a validated source complex can still encode asset artifacts rather than semantic object topology |
| Continuous dynamics | Euclidean rectified flow, manifold diffusion, Schrödinger bridge, Riemannian OT flow, geodesic shooting | Topology-conditioned Riemannian flow matching on positions x SO(3)^V x SPD(3)^V x Euclidean appearance/logits, using explicit geodesics/retractions and exact minibatch assignment only inside identical persistent strata | Rotations remain in SO(3), covariances remain SPD, topology connectivity is fixed. Compatible-stratum Hungarian coupling reduces arbitrary pairing; cross-stratum coupling is rejected because no canonical complex matching is available. | Coupling `O(B_s^3)` per compatible group plus `O(L(E*C+V*C^2))` integration | Cut-locus ambiguity near pi rotations; affine-invariant SPD conditioning; most variable-object batches have singleton stratum groups |
| Hard feasibility | Penalties, log barriers, projected ODE, control-barrier QP, collision-free isotopy solver | Local metric CBF projection, one global speed rescale, explicit primal-margin check, and nonlinear predictor/corrector backtracking; exact KD broad phase under the speed bound | Global positive rescaling preserves all satisfied coupled CBF inequalities for positive state margins. The fixed broad phase contains every pair capable of collision over unit time; every evaluated/accepted integration state is nonlinearly checked. | KD broad phase `O(V log V + J)` expected; reference active dual solve `O(J^2)` time/`O(J^2)` memory | Initial infeasibility; dual nonconvergence; dense collision neighborhoods; shortened predictor makes the safeguarded scheme depart from ideal fixed-step Heun |
| Infeasible transported embedding | Relax collision tolerance, accept numerical epsilon, discard every candidate, soft collision penalty, Euclidean repulsion, metric hard-constraint restoration | Before flow, a sequential linearized QP minimizes evidence-metric displacement subject to normalized strict area/orientation/vertex/triangle inequalities, bounded displacement, merit backtracking, and independent FP64 recertification | The configured hard margins remain unchanged; continuous topology-preserving flow starts only after the selected discrete stratum has a certified interior embedding | One dense active Jacobian and `O(J^2)` dual Gram storage for `J` near-boundary constraints; sparse broad phase bounds `J` in the intended regime | Constraint-qualification failure at an exact degenerate intersection, insufficient displacement budget, or no feasible embedding for the proposed complex causes explicit candidate rejection |
| Gaussian readout | Neural decoder, free 3DGS optimization, per-voxel Gaussian, differential surface sampling | Deterministic curvature-quadrature chart sampling; covariance from first form/curvature plus continuous evidence uncertainty; optical-depth opacity; weighted-ridge SH; conservative projected-tile opacity bound | Centers lie exactly on the atlas, covariance is SPD by construction, opacity lies in `(0,1)`, and appearance solves a convex analytical problem. The tile sum is a true upper bound because every retained footprint is at most one. | Sampling/readout `O(G + E_obs*16^2)` plus bbox-tile incidence | Sparse views make higher SH orders prior-dominated; overlap can still oversample; tile bound may be loose |
| Mesh/asset output | Marching cubes, independent mesh decoder, Poisson reconstruction, atlas complex | PLY Gaussians and GLB mesh serialized from the same selected atlas state and topology complex | No implicit threshold; deterministic byte order; mesh/Gaussian geometry cannot diverge through separate decoders | `O(G)` PLY and `O(V+F)` GLB | A wrong selected complex remains wrong in both outputs; GLB only approximates curved chart interiors unless subdivided |
| Distributed training | Data parallel objects, model parallel backbone, sharded nonlinear OT, replicated global OT, asynchronous topology | DDP model replication; same-object mode autograd-all-gathers the complete evidence measure and replicates one global sparse UOT/atlas solve; discrete state is verified/broadcast by persistent keys | A sum of local UOT barycenters is not falsely identified with a global nonlinear UOT solution. Every rank sees the same evidence, support, Morton identities, and selected stratum; DDP averaging cancels the all-gather backward sum | Communication `O(M*(D+3x3))` and redundant global solve per rank in the reference path; ordinary object DDP uses normal gradient buckets | High feature communication and duplicated compute; object-size stragglers; collective deadlock on rejected samples; future sharded solver requires equivalence proof |
| Repeated-spectrum analytical readout | Unmodified `eigh`, jittering the metric, detached readout, custom arbitrary frame prediction, eigengap-stratified gauge plus basis-free covariance | Exact eigensystem on resolved spectra; frozen forward gauge/common trace derivative on the isotropic stratum; covariance evaluated as `a^2 J J^T + sigma_n^2 n n^T` | Jitter would bias flat geometry and merely choose a hidden direction; detaching destroys surface gradients; learned frames violate analytical readout. The selected method preserves exact forward geometry, isotropic scale learning, SPD covariance, and gauge independence | `O(G)` closed-form 2x2 diagnostics and covariance products; no extra asymptotic memory | Derivative is stratum-conditional at the threshold; exported representative rotations may change gauge across a discrete crossing although covariance remains continuous |
| Non-finite optimizer containment | NaN replacement, skipped local rank, loss scaling fallback, gradient clipping alone, collective fail-fast | Collective named finite checks before backward mutation, before clipping, and after Adam parameter/state mutation; bounded physical calibrator parameters | A skipped rank can deadlock or desynchronize DDP; replacement fabricates a scientific state; clipping a NaN norm corrupts all gradients. Fail-fast preserves the last valid checkpoint and exposes the first bad stage/name | Linear scan over trainable tensors and optimizer state; one int64 all-reduce per gate, object gather only on failure | Additional synchronization overhead; the guard localizes stage/parameter but anomaly mode may still be required to name the originating autograd operator |
| Robust multiview gradients | Arithmetic mean, coordinatewise clipping, geometric median only, full parameter-space SVD, gradient sketches, Gram-space robust subspaces | Phase-F weighted Hilbert geometric median, exact circular-cone projection, exact small-Gram consensus/artifact projectors, then diagonal empirical-Fisher clipping; only view-conditioned losses enter, while global structural gradients remain exact | Parameter grouping is invariant to tensor layout, the cone rejects opposing views, the consensus projector retains jointly supported directions, deterministic color/mask perturbations estimate nuisance directions, and DDP averages only after local purification | `O(K^2 P + K^3)` arithmetic and `O(KP)` retained gradients for `K<=8`, trainable parameter count `P`; no dense `P x K` matrix is allocated | Extra backward passes; Fisher diagonal ignores parameter correlations; artifact perturbations can overlap legitimate appearance learning; consensus fails if most views are wrong |
| Topology-margin adversary | Random perturbation only, simultaneous descent/ascent, persistent adversary, one-step FGSM, multi-step PGD | One-step signed inner maximization of bounded per-block log quantization scales with an RNG-replayed full forward, combined with random camera/depth/confidence/pruning/view perturbations and dimensionless positive certificate slack | The second forward differs only in bounded quantization scale, not stochastic rounding or sampled geometry noise. Hardening loss compares like-with-like normalized margins and retains the exact barrier as zero slack. Multi-step PGD was rejected for the reference path until one-step equivalence and memory are measured. | Two full Phase-F forwards plus scalar scale gradients; adversary state is `O(number of quantized blocks)` | FGSM can under-estimate curved inner objectives; discrete quantization decisions are nonsmooth; random camera perturbations are not a solved worst-case pose attack |
| Quantization topology certificate | Caller scalar margin, Euclidean constraint slack, sampled boundary distance, exact metric constraint gradients | Exact piecewise `min_j h_j/(sqrt(dh_j G^-1 dh_j)+eps)` over the retained position-constraint family, combined with the analytical normalized-score error bound and an explicit externally measured downstream Lipschitz upper bound | The topology distance has consistent displacement units across area, orientation, and squared-separation constraints. No margin or end-to-end Lipschitz constant is fabricated from training losses or local spectral normalization. | Reference gradient loop is linear in constraint count and avoids `O(JV)` retained Jacobian memory; intended for evaluation/certification, not every training microstep | Closest-feature/broad-phase switching is conditional; a loose empirical Lipschitz upper bound makes the certificate vacuous; missing A800 measurement disables rather than passes certification |
| Deep distillation | Final-state only, packed-feature MSE, layerwise gauge loss, dense Jacobian, Hutchinson/JVP matching | World-tensor comparison of all captured `0e/1o/2e` encoder stages plus one deterministic normalized product-manifold JVP; teacher tangents are parallel-transported to the student SO(3), affine-SPD, and irrep gauges | No coordinate-dependent packed-vector MSE is used. Affine transport preserves the SPD metric exactly, and the JVP tests local dynamics without allocating a quadratic Jacobian. One deterministic probe was selected over random Hutchinson probes for exact resume and lower variance across teacher/student. | Activation memory `O(LVC)` in Phase E only; two directional vector-field derivative evaluations instead of a dense state Jacobian | One probe can miss an anisotropic Jacobian error; differing atlas rows make activation loss inadmissible; JVP double-backward raises Phase-E memory |
| VGGT geometric self-supervision | Invented track/normal heads, optical flow teacher, nearest image features, depth-camera cycles, depth finite-difference normals | Deterministic sparse source-depth unprojection, target projection/bilinear depth sampling, world/source cycle closure, and confidence/visibility weighting; neighboring depth rays define a detached world-normal pseudo-target | Uses only released VGGT outputs and audited camera conventions. Track loss remains differentiable to depth/cameras; detached normals prevent renderer/VGGT co-adaptation. No absent modality is silently zero-filled. | Track reference `O(B K^2 HW/s^2)` at stride `s=16`; normal field `O(BKHW)` | Occlusions and repeated surfaces can defeat depth visibility weights; finite differences fail at depth discontinuities; predicted cameras/depth can share a biased self-consistent solution |
| Offline teacher | Independent Gaussian optimization, mesh repair, unconstrained bundle adjustment, topology-fixed atlas bundle adjustment | Robust Cauchy rendering fit over bounded camera SE(3)/intrinsics and a product-manifold tangent to the selected atlas state; hard feasibility backtracking after every optimizer update; common analytical Gaussian/mesh readout and confidence/provenance bundle | Topology cannot change during continuous refinement, all emitted assets share the atlas, and low-consensus teachers are masked rather than called truth. Direct raw-mesh topology never enters the teacher state. | `O(T)` full readout/renders for `T` offline iterations; no student-inference cost | Renderer local minima; topology initialization error is frozen; photometric ambiguity; reference backtracking can shorten large parameter updates; checkpoint execution is external |
| Perceptual supervision | Pixel loss only, fixed gradients, downloaded VGG, pinned VGG, LPIPS | Optional local SHA-256-pinned frozen VGG16 feature pyramid with foreground-mask resampling; deterministic color/gradient pyramid when absent | No runtime network or mutable model hub state enters the objective. Checkpoint identity is exact-resume policy. LPIPS was rejected as a claim because no trained LPIPS calibration/checkpoint is supplied. | Four frozen VGG stages during render phases; activation memory scales with `B K H W` | External checkpoint quality/provenance; VGG domain bias; added Phase-F per-view backward memory; fixed fallback is weaker |
| TRELLIS topology prior | Fuse prior into evidence, candidate-index network, independent-cell Bernoulli, decoded mesh prior | TRELLIS/observed hazard union proposes candidate support; UOT-only occupancy defines evidence/persistence; a Jeffreys-smoothed per-active-cell Bernoulli likelihood scores each candidate under a separate weight | Hidden prior never becomes an observation. Zero TRELLIS votes imply finite absence evidence rather than certainty, and a strong observed likelihood can override the shape prior. A candidate-index network was rejected because candidate ordering is data-dependent and has no pretrained calibration. | `O(CV)` candidate NLL for `C<=12`; no additional decoder | Independent-cell factorization ignores structured correlations; prior resolution/atlas aggregation mismatch; correlated TRELLIS samples overstate effective evidence |
| Precision | FP4 everywhere, BF16 geometry, TF32 acceleration, mixed native precision | Executable policy: configured BF16/FP16 only inside the VGGT aggregator; FP32 heads/atlas/manifold/readout/CUDA rendering/export; FP64 log-domain UOT potentials/implicit probabilities and strict feasibility/certification diagnostics; `highest` FP32 matmul with TF32 disabled | Topological, SPD, transport, and projection decisions never silently use TF32 or BF16 merely because A800 tensor cores support them. Policy identity plus the UOT solve mode is configured/checkpointed. Low-bit execution begins only after equivalence and margin tests. | Higher arithmetic and state cost is accepted on 80 GB A800s; BF16 remains confined to the dominant frozen transformer and FP64 UOT adds linear `E_OT` workspace | Native CUDA splatting is FP32 rather than FP64; nearly singular charts still require FP64 rejection; disabling TF32 and FP64 UOT reduce throughput |
| Gaussian rasterization | Generic differentiable splat, independent reference/CUDA approximations, quaternion scale path, direct analytical covariance path, TRELLIS mip EWA | Shared TRELLIS mip-EWA semantics with exact OpenCV-to-NDC pixel-center map, FOV-clamped EWA Jacobian, determinant-compensated 0.1 screen filter, kernel pruning/termination thresholds, and packed analytical covariance; auxiliary outputs use zero background and alpha/depth share one pass | Reference and optimized paths optimize the same measure-valued image model; covariance is exactly the analytical SPD readout rather than reconstructed through a potentially transposed quaternion convention; nonblack backgrounds do not contaminate alpha/depth/normal | Reference `O(GHW)` within retained tiles; CUDA tile splatting with three passes rather than four, `O(E_pixel)` and `O(G+HW)` state per pass | Tile/depth ordering remains discrete; thresholded tails have zero gradient; extension ABI/source drift; FP32 CUDA accumulation and atomic backward are not bitwise deterministic |
| High-view renderer differentiation | Retain every native rasterizer tape, detach auxiliary channels, reduce resolution/views, stream independent losses, per-view activation recomputation | Non-reentrant deterministic checkpointing surrounds each complete RGB/alpha-depth/normal CUDA view operator; outputs remain resident for the joint loss while native splat tapes are recomputed serially during backward | No view, pixel, Gaussian, channel, loss, precision, or camera is removed. Checkpointing is a trainer execution policy rather than model state, so prior-phase weights remain compatible. The A800 test compares both forward tensors and analytical-Gaussian gradients against the uncheckpointed operator. | Retained native renderer tape decreases from `O(K S_r)` to `O(S_r)` plus `O(KHW)` output tensors and `O(K)` checkpoint metadata; CUDA raster work is approximately doubled during backward | Recompute increases wall time; the extension must be deterministic for a fixed view; irreducible output storage and upstream VGGT/atlas state still grow with `K` |
| Zero-residual geometric norms | Raw Euclidean norm, squared cycle, epsilon-shifted norm, debiased Charbonnier | `sqrt(||r||^2+eps^2)-eps` for world and pixel cycle residuals | It is exactly zero for a closed cycle, locally smooth with finite derivative, and asymptotically Euclidean; raw `sqrt(sum(r^2))` has an undefined zero derivative that produced NaNs in PyTorch 2.4. Squared error changes physical scaling and outlier influence. | Constant work and no added state | `eps` defines a tiny quadratic basin; calibration remains conditional on depth visibility |
| Server environment identity | Import smoke test, loose minimum versions, exact lock audit | Fail-fast comparison of installed distribution metadata with every unconditional `==` pin plus `pip check` | Numerical equivalence, compiled ABI behavior, and the supplied validation result are only interpretable against the declared environment. The audit is read-only and records the requirements digest. | Linear in installed and required distribution count; executed before model import | A pin set does not prove CUDA driver or hardware identity; those remain runtime reports |
| A800 concurrency | Multiple ranks per GPU, artificial reservation, larger Euclidean batch, gradient accumulation, additional views, one object per rank | Exactly one rank per scheduler-visible GPU; object-level DDP across the corpus; same-object validation shards a larger deterministic multiview set; tune views by measured throughput with allocator headroom | Variable topology makes a generic multi-object in-rank batch scientifically and structurally invalid in the current loss/readout contract. More independent objects increase statistical batch through DDP; more views increase geometric coverage. ## Runtime corpus subset versus manifest identity

For smoke validation and one-object diagnostics, the selected formulation is a
validated runtime ID subset applied to an already audited full-corpus
manifest. Rebuilding a catalog-filtered manifest was rejected because it
changes corpus identity and digest; instantiating a full split and indexing one
sample was rejected because object construction performs phase-relative
admission bookkeeping over every remote record. The runtime subset therefore
preserves the manifest as the corpus contract, is checked against the catalog
when one exists, uses the same admission predicate as production loading, and
reduces per-smoke loader work from `O(N)` records to one selected record after
the deterministic manifest scan.

## Bounded precision-to-covariance map

Problem: state initialization and analytical Gaussian uncertainty require a
covariance in a certified interval, while chart writing naturally supplies a
precision. The literal inverse-then-spectral-box composition has an unbounded
intermediate derivative `-M^-1 G M^-1`; the later box cannot retroactively
condition it.

Candidates considered:

- generic inverse followed by eigenvalue clipping: rejected because it uses
  an LU backward and has both singular inverse and repeated-spectrum
  derivatives;
- Cholesky inverse plus a differentiable spectral box: rejected after the
  supplied 32-view A800 reruns because both the backend and exact inverse
  pullbacks still expose the unbounded pre-box inverse;
- log-Euclidean exponentiation: valid but substantially more expensive per
  Gaussian and not inverse-like without an additional learned/scaled map;
- bounded rational functional calculus: selected.

The selected map is
`C(M)=lI+s(I+sM)^-1`, `s=u-l`. It maps every SPD eigenvalue to
`l+s/(1+s lambda)`, commutes with SO(3) conjugation, preserves SPD, has a
bounded Fréchet derivative, and approaches `M^-1` in the resolved interior.
The shifted system has eigenvalues greater than one and is solved in FP64.
This is a deliberate deviation from literal inverse-plus-projection, because
it strengthens the feasibility and numerical invariants without weakening
the probabilistic interpretation.

## Zero-stratum dual norm in sparse feasibility QPs

Problem: a single fixed-width sparse Jacobian stores face, vertex-pair, and
triangle-pair constraints in six local slots. Padding is an exact zero
covector. The literal dual norm `sqrt(g^T G^-1 g)` has an infinite scalar
derivative at that representation zero, and Torch's composition returns NaN
for its mathematically zero metric derivative.

Candidates considered:

- variable-width row storage: exact but complicates every sparse Gram kernel
  and does not remove zero covectors caused by geometric symmetry;
- masking after `sqrt`: rejected because autograd may still evaluate
  `0*infinity` in the inactive branch;
- a custom zero-subgradient square root: finite and exact, but it would no
  longer be an upper bound at zero under roundoff;
- conservative relative-floor norm: selected.

The selected `sqrt(q+delta^2)` uses a detached
`delta^2=eps*max(stopgrad(max q),tiny/eps)`. It upper-bounds every exact local
dual norm and therefore retains the Gram row-sum spectral certificate; the
projected-gradient step may only decrease. Its zero-covector metric derivative
is finite and exactly zero because `dq/dG^-1=g g^T=0`. Complexity and memory
remain `O(J)` and no constraint or gradient row is removed.

VGGT multiscale geometry taps + heads
  -> calibrated evidence measure
  -> sparse implicit KL-UOT
  -> persistent metric-adaptive chart atlas

# 2026-07-25 — Sparse local control-barrier linearization

- Problem: the control-barrier constraints are geometrically local, but the
  implementation asked autograd for a dense `[constraints, vertices, 3]`
  Jacobian and then formed a dense dual Gram matrix.
- Candidates: non-vectorized dense Jacobian (lower transient memory but still
  `O(JV+J^2)`); chunked dense Jacobian (same asymptotic storage); penalty-only
  feasibility (rejects the hard CBF invariant); generic matrix-free JVP/VJP
  (linear memory but repeats the entire constraint graph per dual iteration);
  sparse local derivatives with a matrix-free Gram operator.
- Selection: exact sparse local derivatives. Area/orientation have three local
  vertices, point separation two, and triangle separation six. Batched local
  sum-gradients recover every independent Jacobian row. Scatter/gather evaluates
  `A G^-1 A^T` exactly, and incident dual norms give a Cauchy--Schwarz upper
  bound on its infinity norm.
- Invariants: unchanged active constraint family, evidence metric, dual
  regularization, CBF inequality, global speed rescaling, nonlinear
  backtracking, and FP64 strict-margin recertification.
- Complexity: `O(J+V)` live storage and `O(I(J+V))` dual work for `I` projected
  iterations, replacing `O(JV+J^2)` storage. Conditional guarantee remains
  dependent on fixed closest-feature/active strata and dual convergence.

# 2026-07-25 — Zero-mass attention continuation and offline TRELLIS source

- The raw reliability geometric mean has a singular derivative at a valid UOT
  boundary (`r_i r_j = 0`). An endpoint-normalized Charbonnier continuation was
  selected over clamping (zero-gradient dead zone) and arbitrary epsilon inside
  `sqrt` (endpoint bias). It is monotone, exact at zero/one, and finite-gradient.
- TRELLIS' released `torch.hub.load("facebookresearch/dinov2", ...)` was kept
  architecturally intact but its repository argument is scoped to the already
  installed local Hub checkout. Permitting an opportunistic network fallback
  was rejected because it breaks checkpoint provenance and deterministic
  enterprise-server startup.
